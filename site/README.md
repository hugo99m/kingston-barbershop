# Kingston Barbershop — сайт

Статическая страница без сборки и зависимостей. Достаточно любого веб-сервера,
отдающего папку `site/`.

## Запуск

```bash
cd "/Users/isa/Desktop/Kingston 2.0"
python3 -m http.server 4173 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:4173/

Файл `index.html` можно открыть и двойным кликом, но тогда онлайн-запись
загрузится не везде — браузеры строже относятся к `file://`. Для проверки
записи нужен localhost.

## Структура

```
site/
  index.html            разметка страницы
  assets/css/main.css   вся вёрстка и палитра
  assets/js/yclients.js онлайн-запись
  assets/js/main.js     параллакс, меню, RU/EN, скролл
  assets/img/           визуализации из дизайн-проекта ARCHITEQUE
```

## Онлайн-запись (YClients)

Форма открывается в модальном окне через `iframe`. У страниц YClients не
выставлены `X-Frame-Options` и CSP `frame-ancestors`, поэтому встраивание
работает. Iframe грузится только при первом открытии окна — до этого к
YClients не уходит ни одного запроса.

Все настройки — в начале `assets/js/yclients.js`:

| Параметр | Значение |
|---|---|
| Поддомен филиала | `n131174.yclients.com` |
| ID компании | `140204` |
| Сертификаты | `o1413.yclients.com/loyalty` |

Кнопку записи делает любой элемент с атрибутом `data-book`:

```html
<button data-book>Записаться</button>                          <!-- общий вход -->
<button data-book="master">Выбрать мастера</button>            <!-- список мастеров -->
<button data-book="service">Выбрать услугу</button>            <!-- список услуг -->
<button data-book="service" data-master="sabir">Записаться</button>  <!-- сразу к мастеру -->
```

### Демо-режим

Константа `DEMO` в начале `yclients.js`. Когда включена, кнопки записи
показывают пояснение вместо формы: `src` у `iframe` не выставляется вообще,
к YClients не уходит ни одного запроса, записаться по ошибке нельзя. В окне
остаётся одна кнопка — «Открыть настоящую запись», она ведёт на форму в новой
вкладке.

По умолчанию режим включается сам по имени хоста: на `*.netlify.app`,
`*.github.io`, `*.vercel.app` и `*.pages.dev` — то есть там, где обычно живёт
портфолио. На `localhost` и на боевом домене запись работает по-настоящему.
Принудительно — заменить выражение на `true` или `false`.

## Что надо заменить перед боем

- **Цены.** Взяты с текущего сайта. По Яндексу подтверждаются только стрижка
  шейвером 3 300, моделирование бороды 3 000 и экспресс-уход Solomon's 1 500 —
  остальное сверить с выгрузкой из YClients.
- **Этаж.** На сайте и в дизайн-проекте «2 этаж», в Яндекс.Картах «цокольный».
  Встречается в трёх местах разметки.
- **Фото.** В `assets/img/` лежат визуализации из дизайн-проекта, но тексты и
  подписи написаны так, будто интерьер уже снят: секция называется «Бордо, орех
  и матовое золото», подписи в галерее описывают помещения в настоящем времени,
  в `alt` слова «визуализация» нет. В подвале стоит нейтральный кредит
  «Интерьер — ARCHITEQUE Design Bureau». Когда появится съёмка, файлы просто
  меняются по тем же именам — тексты трогать не нужно.
  Портреты мастеров пока заглушки с гербом.
- **Описания мастеров** с пометкой `[Описание мастера]`.

## Эффект глубины в шапке

Три слоя: фон, слово `KINGSTON`, и та же картинка, обрезанная по кромке стойки
ресепшена и положенная поверх букв. При скролле фон и передний план едут со
скоростью `0.30`, слово — `0.06`, поэтому слово уходит за стойку. На десктопе
слои ещё слегка реагируют на курсор в противоход друг другу, а за курсором идёт
тёплое пятно света.

Геометрия считается в `layoutHero()` в `main.js` по константам исходника
`reception.jpg`:

| Константа | Значение | Что это |
|---|---|---|
| `IMG_W` / `IMG_H` | 1255 / 1567 | размер исходника |
| `EDGE` | 929 | кромка стойки по вертикали |
| `COUNTER_L` / `COUNTER_R` | 0.072 / 0.924 | левый и правый край стойки |
| `WORD_FIT` | 0.88 | какую долю стойки занимает надпись |
| `OVERSCAN` | 1.03 | запас, чтобы не оголялись края при сдвиге |

Размер надписи подбирается под меньшее из двух: ширина стойки × `WORD_FIT` и
90 % ширины экрана — на узких экранах сама стойка шире вьюпорта. Кромка стойки
всегда проходит на `67%` высоты экрана, на мобильном — на `50%`.

**При замене картинки в шапке** надо пересчитать все пять констант и `clip-path`
у `.hero-fg` в `main.css`.

Всё движение отключается при `prefers-reduced-motion: reduce`.

## Атмосфера и интерактив

Всё, что относится к атмосфере, вынесено в `assets/js/atmosphere.js`. Файл
можно отключить целиком, убрав один `<script>` из `index.html` — страница
останется полностью рабочей.

- **Открывающая сцена** — герб, золотая линия, девиз, затем занавес расходится
  в стороны. Показывается один раз за визит (`sessionStorage`), пропускается
  кликом, Esc, Enter или пробелом. Оверлей стоит с атрибутом `hidden`: без
  JavaScript страница открывается сразу, ничего не блокируется.
- **Свет ламп** — пять тёплых пятен, привязанных к светильникам и подсвеченным
  полкам на визуализации. Горят всегда, медленно дышат вразнобой. Координаты —
  массив `LAMPS` в долях кадра.
- **Свет за курсором** — большое золото-бордовое пятно на `mix-blend-mode:
  screen`, догоняет курсор с задержкой. Пока мышь не двигали, светит по центру,
  чтобы шапка не выглядела мёртвой.
- **Пылинки** — canvas с 24–70 частицами, всплывают и покачиваются. Анимация
  останавливается, когда шапка уходит из вида.
- **Курсор** — золотое кольцо с задержкой. Над снимками превращается в диск с
  надписью «Смотреть», над ссылками увеличивается. Системный курсор прячется
  только над шапкой и снимками.
- **Бегущая строка** — девизы бренда на бордо, пауза при наведении. Чистый CSS.
- **Наклон снимков** — картинка в карточке смещается за курсором.
- **Золотые линии** в заголовках секций прочерчиваются при появлении.

Всё перечисленное выключается при `prefers-reduced-motion: reduce` и не
включается на тач-устройствах.

### Прежние элементы

- **Часы клуба** — живой статус в полосе под шапкой: «Открыто · ещё 8 часов»
  или «Закрыто · откроемся в 10:00». Считается по московскому времени
  независимо от часового пояса гостя, обновляется раз в 30 секунд. График
  задан константами `OPEN_HOUR` / `CLOSE_HOUR` в `main.js`.
- **Лайтбокс** — клик по снимку кабинета, залу или ленте интерьера открывает
  галерею: стрелки, клавиши ←/→, Esc, свайп на телефоне. Набор снимков для
  ленты интерьера — массив `INTERIOR` в `main.js`, для карточек — атрибуты
  `data-gallery` и `data-gallery-title` прямо в разметке.
- **Зернистость и виньетка** — два `fixed`-слоя поверх страницы, `.grain`
  и `.vignette`. Зерно нарисовано через `feTurbulence` в data-URI, без картинок.
- **Появление секций** — элементы с классом `.reveal` всплывают при попадании
  в кадр. Правило висит на `html.js`, так что без JavaScript всё видно сразу.
